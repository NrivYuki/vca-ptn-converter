# vca-ptn Converter

眼鏡の玉形（レンズの外形）を、VCA（OMA / DCS）・JOB・PTN・SVG・DXF の間で変換するツールです。ブラウザで開くだけで動き、ファイルはどこにも送信しません。

**公開ページ：** https://nrivyuki.github.io/vca-ptn-converter/index.html

> **前提**
>
> JOB・PTN ファイルの扱いは、[OptiBoard](https://www.optiboard.com/)（眼鏡業界の英語フォーラム）の OMA 関連スレッドと、公開されている各メーカーの取扱説明書から得た情報だけに基づいています。実機が書き出したファイルの中身は確認していません。メーカーごとの JOB・PTN の定義と出典は [docs/job-ptn.md](docs/job-ptn.md) にまとめています。

## 使い方

1. [公開ページ](https://nrivyuki.github.io/vca-ptn-converter/index.html)を開く（手元で使うときは `index.html` をブラウザで開く。サーバーは不要）
2. ファイルをドロップする（または「サンプルを読み込む」）
3. 形と寸法（HBOX・VBOX・周長）を確認し、必要なら設定を変える
4. 書き出したい形式のボタンを押す

## できること

| 読み込み | 書き出し |
|---|---|
| VCA（.oma / .vca / .dcs）。形式 1・2・3、角度モード E・U・C | SVG（単位 mm） |
| 中身が VCA のテキストになっている .job / .ptn | DXF（R12、単位 mm、眼ごとにレイヤー R / L） |
| SVG（曲線・transform・単位に対応） | VCA（REQ=FIL、形式 1、等角度、点数は 360〜1440 から選べる） |
| DXF（LWPOLYLINE・POLYLINE・LINE・ARC・CIRCLE・ELLIPSE・SPLINE） | PTN / JOB（VCA のテキストを、Nidek 機の USB メモリ用の 16 桁の名前にしたもの） |

- 両眼の輪郭が並んだ SVG / DXF は、正面から見て左側を右眼として読み込み、間隔を DBL とします
- 片眼しかないときは、反対の眼を左右反転して作れます
- 輪郭が複数あるときは、いちばん大きいもの（両眼なら大きい 2 つ）を玉形として使います

## ファイル名の決まり

| 対象 | 決まり | 根拠 |
|---|---|---|
| PTN / JOB | 「銘柄名-番号」（ハイフンを含めて 16 桁）か、番号だけ（16 桁）。足りない桁は番号の先頭を 0 で埋める（例：`S1-0000000152152.ptn`、`0000000000123456.ptn`） | ICE 900 の取扱説明書、OptiBoard、販売店の手順書 |
| PTN / JOB | 銘柄名は半角英数字。英字は大文字にする | ME-1000 の取扱説明書（コードの英字は大文字だけ） |
| PTN / JOB | 拡張子は小文字（`.ptn`）か大文字（`.PTN`）を選べる。USB メモリ（FAT32）は区別しない | 資料によって書き方が違うため |
| SVG / DXF / VCA | JOB 番号をファイル名にする。Windows で使えない文字（`\ / : * ? " < > \|`、空白）は `_` に、制御文字は削除、最後の `.` と空白は削る。予約された名前（`CON`、`NUL`、`COM1` など）は先頭に `_` を付ける | Windows のファイル名の決まり |

## できないこと・注意

- **機器が独自の形式で書き出した .job / .ptn は読み込めません。** 形式が公開されていないためです。機器を VCA 出力に設定するか、メーカーの変換ソフトで VCA にしてから使ってください
- 書き出した .ptn / .job を機器が読めるかどうかは、機種や設定によります（OptiBoard では、読めたという報告と読めなかったという報告の両方があります）
- 内側にえぐれた形（中心から見て輪郭と 2 回以上交わる形）は、等角度の VCA では正確に表せません。いちばん外側の輪郭で近似し、警告を出します
- 点数の下限は規格（DCS v3.14）に定められていません。ただし、機器が対応している点数は機種ごとに違います（400 点以上が一般的）。機器が受け付けない点数を送ると、ステータス 17（非対応のトレース形式）が返ることがあります
- Z（サグ）データは、どの形式にも書き出しません
- 穴あけデータは SVG / DXF には書き出しません。VCA・PTN・JOB では、元の VCA に書かれていたレコードをそのまま引き継ぎます
- 形式 4（パックトバイナリ）の VCA は読み込めません
- 単位の書かれていない SVG / DXF は、1 単位 = 1 mm とみなします。違う場合は設定の「1 単位 = ? mm」で直してください

## ファイル

```
index.html       画面
converter.js     変換処理（VCA・SVG・DXF の読み書き、等角度への測り直し、16 桁の名前）
vca-parser.js    VCA の読み書きライブラリ（vca-guide からそのまま使用）
sample-data.js   「サンプルを読み込む」用のデータ
samples/*.vca    サンプルファイル（下記）
docs/job-ptn.md  メーカーごとの JOB・PTN の定義と出典
```

## サンプル

| ファイル | 内容 |
|---|---|
| `frame-right.vca` / `frame-both.vca` / `frame-uneven.vca` | [vca-guide](https://github.com/NrivYuki/vca-guide) のサンプル（360 点・180 点）。画面の「サンプルを読み込む」は `frame-both.vca` を使う。半径の基準点が箱の中心から約 1.32 mm ずれているため、読み込むと警告が出る |
